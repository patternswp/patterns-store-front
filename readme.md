# Patterns Store Front

Patterns Store Front is a modern, block-based WordPress theme that seamlessly integrates with the Patterns Store plugin, developed by the core team at PatternsWP.com. Designed for designers and developers, it provides an elegant way to showcase pattern kits and individual patterns. With Full Site Editing (FSE) support, users can easily customize headers, footers, and layouts via the WordPress block editor. The theme includes responsive, pre-designed templates that beautifully display pattern collections, offering a visually engaging experience across devices, and making it perfect for organizing and presenting pattern design assets professionally.

Primary color: `#48B44F`.

![screenshot](./screenshot.png)

## Features

- 3 hero and landing patterns
- 5 card layouts (card-1 through card-5)
- 1 FAQ pattern
- 9 archive/post-listing patterns
- 2 contact page patterns
- 1 menu navigation pattern
- 12 section layout patterns (featured sections and section titles)
- Full Site Editing (FSE) support
- Responsive design
- 82 block patterns + 24 templates + 11 template parts
- Pattern store oriented layouts (browse, filter, single pattern details)

## Requirements

- WordPress 6.6 or higher
- PHP 7.0 or higher
- Tested up to WordPress 6.7

## Development

This theme uses `@wordpress/scripts`:

```sh
npm install
npm run start    # dev mode with watch
npm run build    # production build
```
